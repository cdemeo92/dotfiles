# zoxide

`zoxide` learns the directories you visit and lets you jump to them by name. Its Zsh initialization defines the `z` and `zi` commands.

## Install

```bash
bash 011-zoxide/install.sh
```

## Quick reference

| Task                                     | Example           |
| ---------------------------------------- | ----------------- |
| Jump to a frequently used directory      | `z projects`      |
| Jump using multiple parts of its path    | `z dot files`     |
| Choose a directory interactively         | `zi`              |
| Show the database of visited directories | `zoxide query -l` |
