# fzf

`fzf` is an interactive fuzzy finder for files, command output, and other lists.

## Install

```bash
bash 007-fzf/install.sh
```

## Quick reference

| Task                               | Example                   |
| ---------------------------------- | ------------------------- |
| Find files interactively           | `fzf`                     |
| Select an item from command output | `git branch --all \| fzf` |
| Search files by name               | `find . -type f \| fzf`   |
